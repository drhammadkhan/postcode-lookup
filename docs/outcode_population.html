Methodology — outcode catchment, postcode-count weighted: Catchments are defined by outward code (e.g. SE1, NW3) using the clinical mapping in the Outcode Approach. Where an outward code lists multiple hospitals, values are split in proportion to how many full postcodes from that outcode are already routed to each hospital in the full-postcode dataset. Falls back to equal split for non-residential outcodes. Births data uses ONS 2016–2018 3-year combined totals at postcode-sector level, aggregated to outward code.
