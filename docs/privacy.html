Privacy

Privacy and data use

HO.ME is designed to perform postcode lookups in the browser and collect only limited, aggregate information about searches.

Postcode lookups

HO.ME only searches postcodes. It does not ask for names, street addresses, NHS numbers or patient details.

The postcode lookup dataset is downloaded to your browser. A postcode entered into the search box is matched against that local dataset; the full postcode is not sent to the search-statistics service.

After a successful search, the postcode is added to the page URL as a postcode parameter so the result can be bookmarked or shared. If that page URL is shared, opened or reloaded, the URL, including its postcode parameter, may appear in standard web-hosting request logs.

Aggregate search statistics

When a syntactically valid postcode is searched, HO.ME derives its postcode sector, such as SE1 7, and records the sector together with whether the postcode was found in the lookup dataset. This allows aggregate demand and out-of-area searches to be counted without storing the full postcode in the search-statistics store.

The tracking store contains counters by postcode sector and outcome. It does not contain names, user accounts, patient records, street addresses or full postcodes.

Technical providers

The site is delivered using GitHub Pages and Cloudflare. Mapping resources are loaded from unpkg and OpenFreeMap. Like most web services, these providers may process standard technical information such as IP address, browser details and requested page URLs to deliver and protect their services.

If you choose to use the HO.ME feedback form, the information you submit is handled by Microsoft Forms.

Cookies and advertising

HO.ME does not set first-party cookies, create advertising profiles or include advertising trackers.

Questions

For questions about this page or how HO.ME handles search information, please use the HO.ME feedback form.
